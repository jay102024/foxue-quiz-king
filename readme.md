# 佛學知識王 — 使用說明

> 一套可離線執行的佛學問答遊戲。單機啟動,瀏覽器遊玩,題目與成績都存在本機。

---

## 一、怎麼開始玩

### Windows

1. 把整個「佛學知識王」資料夾**解壓縮出來**(不要在壓縮檔裡直接執行)。
2. 雙擊資料夾裡的 `啟動.bat`。
3. 會跳出一個黑色小視窗,約 3 秒後自動打開瀏覽器進入遊戲。
4. 想結束時,直接關閉那個黑色視窗即可。

> ⚠️ 那個黑色視窗請**不要關閉**,關掉它遊戲就停了。

**不用另外安裝任何東西** —— 本資料夾已內含執行環境(`runtime` 資料夾裡的 `node.exe`),
對方電腦不需要先裝 Node.js 或任何程式,解壓後直接雙擊就能玩。(適用 64 位元 Windows 10/11)

### Mac

1. 先安裝 Node.js:到 <https://nodejs.org> 下載 macOS 版 LTS 安裝(**需 22.5 以上**)。
   Mac 版沒有內含執行環境,這一步一定要做,**只要做一次**。
2. 把整個「佛學知識王」資料夾解壓縮出來。
3. 開啟「終端機」,輸入 `cd ` 後把資料夾拖進視窗按 Enter,再執行一次:

   ```bash
   chmod +x 啟動.command
   ```

   這是給檔案執行權限,**只要做一次**。
4. 之後每次玩,雙擊資料夾裡的 `啟動.command` 即可,
   會開啟終端機視窗,約 3 秒後自動打開瀏覽器進入遊戲。

> ⚠️ 那個終端機視窗請**不要關閉**,關掉它遊戲就停了。

想讓 Mac 也做到免安裝?到 nodejs.org 下載 macOS 版壓縮檔,把裡面的 `bin/node`
改名成 `node-mac` 放進 `runtime` 資料夾,`啟動.command` 會優先使用它。
(注意 Apple Silicon 是 arm64、Intel 是 x64,要下對版本。)

### 全螢幕

遊戲畫面本身就是**滿版設計**(整個瀏覽器視窗都是遊戲畫面)。
投影或想更沉浸時,可以按右上角的 **⛶** 按鈕、鍵盤 **F**,或瀏覽器的 **F11**,
進入不含網址列的真全螢幕;再按一次或按 `Esc` 離開。

## 二、第一次執行的系統警告

| 系統 | 畫面 | 怎麼處理 |
|------|------|----------|
| Windows | 藍色的「Windows 已保護您的電腦」 | 點「更多資訊」→「仍要執行」 |
| Mac | 「無法打開,因為來自未識別的開發者」 | 在 `啟動.command` 上按右鍵 →「打開」→ 再按一次「打開」 |

兩者都只是因為檔案來自網路,**並非病毒**。

Mac 也可以改用終端機指令解除:

```bash
xattr -d com.apple.quarantine 啟動.command
```

## 三、兩種模式

- **單人挑戰**:限時搶答,分數與連擊。
- **雙人對決**:兩人比分,答對得分、答越快分數越高,10 題後比總分。

每答完一題(答對、答錯或時間到)都會跳出**解說頁**:
畫面用黑色半透明遮罩蓋住題目,上面顯示正解與這一題的說明,
右下角按「下一題 →」(也可以按 Enter 或空白鍵),
會先出現「**第 N 題**」的過場,再進入下一題。最後一題按的是「看成績 →」。

作答方式可用滑鼠、鍵盤或藍牙搶答按鈕。鍵盤對應:

| 玩家 | 按鍵 |
|------|------|
| 玩家一 P1 | `1` `2` `3` `4` |
| 玩家二 P2 | `7` `8` `9` `0` |

## 四、排行榜

- 每個分類(煩惱診療室 / 熟悉又陌生的詞彙 / 翻轉傳統迷思 / 佛系密碼大解謎)各有**一份獨立排行榜**,只留**前 20 名**。
- 遊戲進行中,分數旁邊會顯示「與第一名的分差」(領先會變成綠色的 `+分數`)。
- 一局結束時,如果成績擠進該分類前 20 名,會**跳出一個小視窗**請你輸入玩家名,
  按「登錄上榜 →」就會寫進資料庫,接著自動進入排行榜(你那一列會標亮)。
  - 不想留名可按「略過」。
  - 沒擠進前 20 名則直接進入排行榜,並顯示還差幾分。
- 雙人對決兩位玩家**分開計算**,誰上榜誰就在同一個視窗裡輸入名字。
- 排行榜是**完整的一整頁畫面**,不是小彈窗:
  - 上方可切換煩惱診療室 / 熟悉又陌生的詞彙 / 翻轉傳統迷思 / 佛系密碼大解謎;
  - 按左上角「← Back」回到剛才的畫面,或按「回首頁 Home」;
  - 首頁和結果畫面的「排行榜」按鈕可隨時進去看。
- 成績和題目一樣存在 `foxue.db` 裡;要清空榜單請到後台 `/admin` 的「排行榜管理」。

## 五、管理題庫(後台 /admin)

啟動後,在瀏覽器網址列輸入(Windows / Mac 都一樣):

```
http://localhost:3000/admin
```

### 1. 一題一張卡片,直接編輯

題庫區塊每一題都是一張卡片,上面看得到題目、四個選項(正解那格是綠色)、解說和分類。
卡片右邊的按鈕就是這一題能做的事:

| 按鈕 | 做什麼 |
|------|--------|
| **↑ ↓** | 把這一題往前 / 往後移(遊戲出題順序) |
| **✎ 編輯** | 打開編輯視窗,一格一格改 |
| **⧉ 複製** | 複製成新的一題(接在原題後面),適合出相似題 |
| **🗑 刪除** | 刪掉這一題 |
| **煩 / 詞 / 迷 / 密** | 點一下就把這題加入 / 移出該分類(亮起＝屬於) |

最上面的 **＋ 新增題目** 開的是同一個編輯視窗,填完按儲存就多一題。
**改完立刻寫進資料庫,不需要再按整批儲存。**

### 2. 編輯視窗:每個欄位一格

| 欄位 | 說明 |
|------|------|
| **題目** | 必填,最多 300 字 |
| **選項 A~D** | 四格都要填;左邊的圓鈕點哪一格,那格就是**正解** |
| **分類** | 四顆膠囊,**可複選**;沒選會自動放進「煩惱診療室」 |
| **解說** | 玩家答完這題會看到,可留空,最多 500 字 |

遊戲進行時選項會自動打亂,所以正解放在哪一格都沒關係。
視窗裡按 **Esc** 取消、**Ctrl + Enter** 直接儲存。

### 3. 找題目與批次處理

- 上方的**搜尋框**可搜題目、選項、解說的文字。
- **篩選**膠囊可只看某一個分類,括號裡是該分類的題數。
- 勾選卡片左上角的方框後,可以**批次加入 / 移出分類**,或**批次刪除**。

### 4. 備份與整批編輯

「備份與整批編輯」面板展開後,是舊的一行一題文字格式,適合一次貼上大量題目:

```
題目｜選項A｜選項B｜選項C｜選項D｜正解｜分類｜解說
```

用「｜」分隔,**6 到 8 欄**。正解填 A~D 或 1~4;分類可填完整名稱、1~4 或 煩/詞/迷/密,
一題要屬多個分類就用 **/** 分隔。這裡按「儲存到資料庫」會**覆蓋整個題庫**,所以會先跳出確認。
同一個面板也有**下載備份 / 匯入檔案 / 還原預設題庫**。

題目與成績都存在 `foxue.db` 這個檔案裡;**要備份就複製這個檔即可**。

## 六、用手機或平板玩

遊戲主機(跑 `啟動.bat` / `啟動.command` 的那台電腦)開著的時候,
同一個 Wi-Fi 下的手機、平板可以直接連進來玩:

1. 在主機上查區網 IP —— Windows 用 `ipconfig`、Mac 用「系統設定 → 網路」。
2. 手機瀏覽器輸入 `http://<那個IP>:3000`。

> Windows 第一次可能會跳防火牆詢問,要允許在**私人網路**通訊,否則手機連不進來。
>
> iPhone / iPad 只能當**玩家端**,不能當主機(伺服器需要電腦執行)。
> 另外雙人對決的兩顆藍牙按鈕同時配對到 iOS 並不穩定,建議對決還是在電腦上跑。
