02 — Backup & Bulk Edit

備份與整批編輯

展開整批文字編輯 (一次貼上大量題目、下載備份、匯入檔案、還原預設題庫)
每行一題,用「｜」(或半形 |)分隔,6 到 8 欄:
題目｜選項A｜選項B｜選項C｜選項D｜正解｜分類｜解說
正解填 A / B / C / D(也可填 1~4)。分類可填完整名稱,也可填 1~4 或 煩 / 詞 / 迷 / 密; 一題要屬於多個分類就用 / 分隔,例如 …｜B｜煩惱診療室/翻轉傳統迷思。
以 # 開頭或空白行會被忽略。按下「儲存到資料庫」會用這裡的內容覆蓋整個題庫。
